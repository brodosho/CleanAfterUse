# Clean After Use


### Overview
**Clean After Use** is a personalised gym app that tracks your workout sessions, in a classic zero to hero style progression. It can suggest workouts for you using data from r/Fitness wiki and MyFitnessPal workout sessions. Perfect for beginners as it suggests when to move onto the next level. An ELO system can be used to track your progress against real gym pros.

### Stack
## **Frontend:** HTML5

### Why I built this
I have been using notes to create my gym routines, track my weights, pick what weights to change, count my sessions, and an overall format of how I choose to workout. While it works fine, there is a lot of wasted time entering figures into my phone, which can all be neatly presented in a clean HTML style phone app.

### "I want to use this myself"
This app is meant for anyone and everyone, and can simply be added to your phone by cloning, creating a page and adding the url to your homescreen.

### What's next
I have spent lots of time making this app clean to use, simple but complicated if you want it to be. My next venture would be to make more accurate diagrams and polish up the ELO system a bit more.
